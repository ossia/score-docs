# Data processing

A sensor value is not yet an artistic response. You may want to enlarge a small movement, wait for two participants, move a gesture across many destinations, or generate variation without a performer. These examples let you study those decisions through plots and value displays before connecting them to sound, light or images.

## Choose a response

- **Make a gesture fit its destination:** start with [Math expressions and structured objects]({{ site.baseurl }}/examples/data/maths-and-objects.html). Change the scale and offset of a signal, then explore how to extract useful values from a larger message.
- **Control when a response happens:** try [Mapping and event utilities]({{ site.baseurl }}/examples/data/mapping-overview.html). Filter repeated input, retain a short history, or wait for fresh events from two sources.
- **Treat many destinations as an ensemble:** open [Address pattern tools]({{ site.baseurl }}/examples/data/address-tools.html). Distribute a list of values or move a signal through a group instead of wiring every destination individually.
- **Let a gesture evolve by itself:** use [Delayed value feedback]({{ site.baseurl }}/examples/data/value-feedback.html). Compare a recurrence that settles with one that keeps varying.

For a short first exercise, open the feedback example and change its coefficient from 3.68 to 2.5. Watch the trace settle, then restore the original value. The difference is a compositional choice between stability and ongoing variation; the example visualizes the control signal rather than producing sound.
