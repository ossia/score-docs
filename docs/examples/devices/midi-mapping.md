# MIDI controls for a shader

![MIDI note filtering and smoothing connected to Triangle Square Twist over its generated line pattern]({{ site.baseurl }}/assets/scores/thumbnails/examples-devices-midi-mapping.png)

Perform an abstract image from a MIDI keyboard. The modulation wheel zooms a line pattern, pitch bend couples rotation with amplitude, and notes reshape and twist the drawing.

The image is generated by the native ISF shader Triangle Square Twist. No video or model file is needed, and the patch produces no sound.

## Connect and play

1. With playback stopped, right-click `MIDI In`, choose Edit and select your actual MIDI input. The saved default port may not exist on your machine.
2. Use Learn on that device and move your controls if their addresses are not present. Confirm values change in the Device explorer before starting playback.
3. Start playback and send channel 1 CC1 (`MIDI In:/1/control/1`) to control zoom. Channel 1 pitch bend changes rotate and amplitude together.
4. Send note 36 on channel 10 with different velocities to change the shader's triside1 control. This percussion-style input uses a different channel from the wheels.
5. Play a run of notes to change twist. Note values are normalized and smoothed, so the image travels between settings instead of simply snapping from one to the next.

## Try it

Alternate low and high notes while leaving the wheels still. Raise Exp Smoothing's Alpha from its saved 0.01 toward 1: the pattern stops flowing between notes and starts following individual attacks.

Then combine pitch bend with the modulation wheel to rotate and zoom at once. To try a different physical control, learn its address and drag it onto the relevant shader inlet, or edit the inlet's address. A direct mapping like this has no conversion or smoothing; the note-to-twist chain uses conversion to set the range and smoothing to set the timing.
