# Tempo Examples

Changing time can reshape a passage as much as changing its notes. A loop can accelerate with or without a pitch shift, and two layers can keep different metres while playing together.

Start with [Tempo manipulation]({{ site.baseurl }}/examples/tempo/tempo-control.html) to hear these in one score: the same drum recording plays in re-pitching and time-stretching sections, then with a tempo driven by a changing control signal.

## Choose the right timing tool

Use the [Tempo process]({{ site.baseurl }}/processes/tempo.html) to control musical speed. Use [Free Metronome]({{ site.baseurl }}/processes/metronome.html) when you need timed impulses; it is not an external transport synchronizer. Check whether a control uses musical divisions or an absolute duration before deciding how it should respond to a tempo change.

For external equipment, [MIDI Sync Out]({{ site.baseurl }}/processes/midi-sync.html) sends synchronization and [MIDI Sync In]({{ site.baseurl }}/processes/midi-timecode-input.html) decodes it. [Timecode Synchronizer]({{ site.baseurl }}/processes/timecode-synchronizer.html) follows a time position. These are reference pages for connecting a larger performance setup, not additional downloadable examples.
