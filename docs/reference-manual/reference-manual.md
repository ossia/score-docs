# *score* reference manual

This section of the manual goes through the various sections of *score* and bring detailed explanations.
{: .fs-6 .fw-300 }

## Finding a feature

- [[Processes]] and [[Devices]] describe the objects and connections available in a score.
- [Languages]({{ site.baseurl }}/reference/languages.html) collects syntax and APIs for JavaScript/QML, ExprTK, Faust, GLSL and score's shader formats, C++, and other embedded languages.
- [[Appearance and skins]] explains interface colors, font roles and readability settings.
- [[Editing workflow]] covers scrubbing, patch editing, live changes and reference repair.
- [[Time Chooser]] explains free and musical timing controls.
- [[Project files]] covers missing media, consolidation and project archives.
- [[Add-ons]] distinguishes installed capabilities from optional source extensions.
