# Text Box

Text Box is an editable annotation process. Double-click its text to edit it in place; its **in** control stores the text.

With **Auto-reflow** enabled, text wraps to the box width, so resizing the process changes line wrapping. With Auto-reflow disabled, the box grows to fit the longest line instead. Use it to label patch regions, document a mapping, or leave performance instructions beside the processes they describe.

Text Box is not the graphics [Text]({{ site.baseurl }}/processes/text.html) renderer. For monitoring incoming values, use [Value Display]({{ site.baseurl }}/processes/value-display.html).
