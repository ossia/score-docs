# Matrix

The process is named Matrix spatialization in the process library. It distributes a mono source across output channels using a list of gains.

See [[Matrix Spatialization]] for its ports, channel-offset behavior and an example. For independent moving sources, use one instance per mono source and mix the resulting multichannel outputs.
