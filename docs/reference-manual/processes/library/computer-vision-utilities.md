# Computer vision

Computer vision utilities provide classical image filtering and analysis, blob and contour processing, and feature and motion analysis through the optional CV add-on. See [Add-ons]({{ site.baseurl }}/reference/add-ons.html#extension-families) for availability and graphics requirements. For model-based detection and pose estimation, see [AI Recognition]({{ site.baseurl }}/processes/ai-recognition.html).
