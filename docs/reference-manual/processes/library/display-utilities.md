# Display Utilities


Use display processes to inspect data without changing the signal being monitored. Connect a source to a display alongside its normal destination.

| Process | Use |
|---|---|
| [Value Display]({{ site.baseurl }}/processes/value-display.html) | Inspect recent values and observe a light on each arrival, even when a value repeats |
| [Signal Display]({{ site.baseurl }}/processes/signal-display.html) | Plot control histories with automatic or fixed numerical ranges |
| [LED View]({{ site.baseurl }}/processes/led-view.html) | Inspect long arrays as colored or grayscale cells |
| [Point2D View]({{ site.baseurl }}/processes/point2d-view.html) | Inspect two-dimensional positions |
| [Text Box]({{ site.baseurl }}/processes/text-box.html) | Add editable annotations with optional line wrapping |

A display is a monitoring surface, not a network or physical-lighting output. For pixel extraction, see [Pixel Utilities]({{ site.baseurl }}/processes/pixel-utilities.html); for routing and manipulating values, see [Mapping utilities]({{ site.baseurl }}/processes/mapping-utilities.html).
