# Kinect

Kinect v1 (Xbox 360), Kinect v2 (Xbox One) and the Azure Kinect DK are supported by the [Depth cameras]({{ site.baseurl }}/devices/depth-camera-device.html) device,
since ossia score 3.9.0. It provides their color, infrared and depth images, point clouds, inertial sensors and, on the Kinect v1, the tilt motor and LED.
